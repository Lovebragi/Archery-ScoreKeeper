# 射箭计分器更新日志

射箭计分器应用的发布历史。仓库级的[更新日志](../CHANGELOG.zh_CN.md)记录 AI
Passport 项目本身；本文件跟随应用的固件版本。

## 1.2.0 — 2026-10-25

### 新增

- 在手机配网页 `192.168.4.1` 下载完整训练记录的 UTF-8 CSV：每次训练一行，
  含日期、靶型、组数、箭数、总环、平均、内十、脱靶与各环值箭数，可直接用
  Excel 打开。
- 屏幕左上角显示固件版本号。

### 调整

- 联网菜单项改为「手机配网 / 导出」，配网页在配置网络之外提供 CSV 下载。

## 1.1.0 — 2026-10-25

### 新增

- 「联网」页：扫描附近 Wi-Fi、在设备上直接输入密码，或通过开放热点
  `Archery-Setup` 与 `192.168.4.1` 网页用手机配网。
- 联网后按 UTC+8 做 NTP 对时，时钟写入 NVS。
- 顶部状态栏显示当前时间（时:分）、联网状态圆点与电量。

### 调整

- 默认屏幕亮度改为 20%，息屏时间改为 15 秒。
- 配网热点为开放网络（无密码），且只在联网页显示期间存在。

### 修复

- 联网菜单在首次扫描前无法移动光标。
- 密码连发没有跟随屏幕 180° 的角色旋转。
- 配网网页因热点开启时扫描而一直显示“扫描中”；现在先用扫描缓存并提供刷新按钮。

## 1.0.0 — 首次公开版本

- 支持 40 半靶、三联靶与 40/80/122 全靶。
- 按环值录入箭数，统计本组/累计/平均/内十/脱靶。
- 最近 300 条带时间戳记录，支持全部/今天/最近 7 天筛选。
