# 射箭计分器（半靶与全靶）

面向 40 半靶、三联靶和 40/80/122 全靶训练的计分工具。运行在 FoloToy AI
Passport 上，可配置组数与每组箭数，把最近 300 次训练（带时间戳）保存在 NVS，
并可按"全部 / 今天 / 最近 7 天"筛选查询。联网页可选连接路由器做 NTP 对时，
既支持手机扫码/网页配网，也支持在设备上直接输入 Wi-Fi 密码。应用自己接管
屏幕与三个按键，不需要音频或云账号。

## 计分口径

在设置里可以选择五种靶面：

| 靶型 | 靶面环区 | 录入项 |
| --- | --- | --- |
| 40 半靶 | 6~10 环 + 内十 | X、10、9、8、7、6、0 |
| 三联靶 | 三个 40 半靶，环值同上 | X、10、9、8、7、6、0 |
| 40 全靶 | 0~10 环 + 内十 | X、10、9 … 1、0 |
| 80 全靶 | 0~10 环 + 内十 | X、10、9 … 1、0 |
| 122 全靶 | 0~10 环 + 内十 | X、10、9 … 1、0 |

所有靶型的 0 都表示脱靶。设置里关闭「记录内十」后，录入页不再列出 X，
10 环同时包含内十。三联靶保留三个独立靶面：设置页除了每组箭数，还要
确认上靶、中靶、下靶各几根箭（默认 2 / 2 / 2，三者之和必须等于每组箭数），
录入时按上靶 → 中靶 → 下靶依次记录，每个靶面记满后自动切到下一靶。每根箭
编码为：

| 编码 | 含义 | 计分 |
| --- | --- | --- |
| `0` / `M` | 脱靶 / 0 环 | 0 |
| `1` … `9` | 环值 | 1 … 9 |
| `10` | 十环 | 10 |
| `X` | 内十 | 记 10 环，单独统计用于同环决胜 |

总环数、每组环数、内十数、脱靶数、最佳单组与平均每箭环数都由这些编码推导；
平均值保留一位小数并四舍五入。靶型随每次训练一起保存，历史详情会按同一套环值
表展示。

## 页面与按键

屏幕方向可在设置里选择"倒转"（默认）或"正常"。`bsp_pins.h` 的
`BSP_LCD_ROTATE_180` 是开机默认值，应用在显示初始化后立即按保存的设置重新
下发。三个键是机身侧边自上而下的一列，按键角色跟随屏幕方向：倒转时角色整体
旋转 180°（物理上键当确定、物理下键仍是下、物理确定键当上），正常方向时保持
自然含义。切换这一项时，画面与按键映射同时改变。

| 页面 | 内容 | 上 / 下 | 确定 | 长按确定 |
| --- | --- | --- | --- | --- |
| 主页 | 靶环图案、四个入口、时间与联网状态、电量 | 选择入口 | 进入 | – |
| 新训练 | 组数、每组箭数、三联靶的上/中/下箭数、开始 | 调整当前项 | 下一项 / 开始 | 上一项（首行返回主页） |
| 设置 | 靶子类型、屏幕方向、屏幕亮度、息屏时间、记录内十、日期时间 | 调整当前项 | 下一项 / 进入对时 / 保存并返回 | 保存并返回 |
| 录入 | 两列排布的本组各环箭数 + 提交行（三联靶每次一个靶面） | 修改当前环的箭数 | 下一环 / 提交行 | 返回上一环（首行则放弃确认） |
| 小结 | 本组成绩、累计、组进度点 | – | 下一组 / 总结 | 放弃确认 |
| 完成 | 总环数、平均、内十/脱靶、保存状态 | – | 返回主页 | 返回主页 |
| 历史 | 带时间戳的训练记录（最近 300 条）、全部/今天/最近 7 天筛选、清空与返回（空历史也保留"返回主页"行） | 移动光标 | 查看详情 / 清空 / 回主页 | 切换筛选 |
| 联网 | 连接状态、扫描/手机配网/立即对时/断开/返回 | 移动光标 | 执行 | 返回主页 |
| Wi-Fi 密码 | SSID、已输入密码、当前字符 | 换字符（长按连发） | 下一位 / 连接 | 删除 / 返回 |
| 详情 | 某次训练的某一组，按同样的各环箭数展示 | 上一组 / 下一组 | 返回 | 返回 |
| 确认 | 放弃本次训练 / 清空历史 | 选择选项 | 执行 | 取消 |
| 日期时间 | 年、月、日、时、分 | 调整当前字段 | 下一项 / 保存 | 保存 |

一组成绩按"每个环值落了几根箭"记录，而不是一根一根录入：录入页依次列出 X（可在
设置里关闭）、10、9、8、7、6、0，每行填箭数。计数从 0 开始，合计等于每组箭数时提交行才
接受确定，所以累计环数是从 0 往上加的，不会从满环往下扣。提交行会显示还差几根
箭，或者本组合计环数。箭数一凑满，按确定会从当前环值行直接跳到提交行，再按一次
即提交本组，不必逐行穿过剩余的空行。

## 数据存储

- NVS 命名空间 `archery`。
- 每条记录一个 blob，键为 `s000`…`s299`；`meta` 保存下一个序号。槽位按
  `(seq - 1) % 300` 固定映射，因此最近 300 次总能定位，且无需重写旧记录。
  NVS 分区为 256 KB，300 条 12×12 的满配置也放得下。
- 记录含版本号与 CRC-16/CCITT 校验。校验失败的记录被忽略；启动时全量扫描并
  修复 `meta`，保留最新一段连续有效记录。
- 记录保存组数、每组箭数、靶型、用时（秒）、时间戳与 4 bit 打包的环值
  （144 箭只需 72 字节）。早期没有靶型/时间戳字段的记录仍可解码，按 40 半靶与
  "时间未知"处理。
- 清空历史只删记录与 `meta` 并把序号重置为 1；设置与时钟保留。
- 设备没有电池供电的 RTC。时钟 = 持久化的本地时间 + 单调计时：通电期间自动
  走时，断电后从上次保存的时间继续；可在设置里手动校准，也可联网后用 NTP 对时。
  历史筛选依赖这个时钟；时间未知的记录显示 `--`。

## 导出历史

联网页可以把完整历史交给手机或电脑，不需要额外软件：

1. 进入 **联网 -> 手机配网 / 导出**，设备会开开放热点 `Archery-Setup` 并显示二维码。
2. 手机或电脑连接 `Archery-Setup`，打开 `http://192.168.4.1/`。
3. 点 **下载训练记录（CSV）**。

文件为带 BOM 的 UTF-8，每次训练一行：日期、时间、靶型、组数、每组箭数、
总箭数、总环数、平均、内十、脱靶，以及 X、10 … 0 各环值的箭数，可直接用
Excel 打开。导出与配网共用同一个临时热点，设备不需要连接路由器。

## 字库

数字使用 LVGL 自带 Montserrat 20/40；中文使用按 UI 字符串生成的 Noto Sans SC
子集：

- `assets/fonts/archery_chars.txt`：非 ASCII 码点清单。
- `assets/fonts/archery_font_16.c`、`archery_font_20.c`：生成的 LVGL 字体
  （4 bpp、PLAIN、无 kerning，位图约占 79 KB Flash）。
- `assets/fonts/archery_font_16.json`、`archery_font_20.json`：每个字形的校验值，
  供静态检查核对。

`tools/gen_lvgl_text_font.py` 用 Pillow/FreeType 光栅化并直接输出 LVGL 格式；
`tools/lvgl_font_tools.py` 按 LVGL 的读取方式把生成的 C 文件解析回来；
`tests/test_archery_fonts.py` 在 UI 文本出现字库/清单未覆盖的字符时失败，使缺字
在静态门禁暴露，而不是到设备上变成占位方框。运行期每个标签也会把缺失字形以
`U+XXXX` 打进日志。

新增中文文本后按下面的命令重新生成两个字级：

```bash
python tools/gen_lvgl_text_font.py \
  --font NotoSansSC-VF.ttf --weight 400 --size 16 --name archery_font_16 \
  --inventory assets/fonts/archery_chars.txt \
  --scan main/archery_ui.c main/archery_score.c --update-inventory \
  --output assets/fonts/archery_font_16.c --manifest assets/fonts/archery_font_16.json
```

源字体与许可记录见 [`assets/README.md`](../../assets/README.md)。

## 功耗行为

主页第三项是"设置"，包含以下设置项：

| 设置项 | 可选值 | 默认 |
| --- | --- | --- |
| 靶子类型 | 40 半靶 / 三联靶 / 40 全靶 / 80 全靶 / 122 全靶 | 40 半靶 |
| 屏幕方向 | 倒转 / 正常 | 倒转 |
| 屏幕亮度 | 20 / 40 / 60 / 80 / 100% | 20% |
| 息屏时间 | 0 / 15 / 30 / 60 / 120 秒（0 = 不息屏） | 15 秒 |
| 记录内十 | 开 / 关 | 开 |

空闲达到设定时间后，应用关闭背光、关闭显示输出、把共用按键脚交回数字输入，
然后进入浅睡。任意键立刻唤醒：按设置的亮度恢复显示、回到原来的页面，训练状态
仍在 RAM 里，不需要重启或写快照。唤醒的那一下按键只负责唤醒，松手前的按键事件
都会被丢弃，所以不会误提交或误进入下一项。

应用刻意不使用 deep sleep：未提交的训练只在 RAM 里，而 deep sleep 唤醒会重启
芯片。没有中间的自动调光阶段，亮度只由设置决定。电量计每 10 秒读一次，在右上角
（用户视角）以细条显示；读数不可用时只画空心电池壳，不显示假百分比。

## 构建与测试

```bash
source <path-to-esp-idf-v5.5.3>/export.sh
./tools/validate.sh            # 仓库检查、主机测试、固件门禁
```

固件门禁把 0x0 合并镜像写到 `build/FoloToy-AI-Passport-full.bin`，并在
`build/firmware/<sha256>/` 保留匹配的调试产物。完整刷新只烧这个合并镜像；
`idf.py flash` 仍用于日常增量开发。
